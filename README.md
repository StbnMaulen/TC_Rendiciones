# Mis Boletas · True Controls

PWA local para registrar boletas de gastos y generar el PDF de la rendición. Sin servidor, sin
cuentas y sin conexión: los datos viven en el teléfono de cada persona.

**La documentación completa está en [LEEME.md](LEEME.md)** — instalación, publicación en GitHub
Pages, cómo se usa, dónde se guardan los datos y qué es (y qué no es) el respaldo JSON.

```
index.html              La app completa
manifest.webmanifest    Instalación (nombre, íconos, colores)
sw.js                   Service worker (cache offline)
icons/                  Íconos
```
